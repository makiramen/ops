CJ2 ontology · domain model (PIM) · proof v0.2

Plain English names, only what CJ2 touches. Each class notes the system that holds it (PSM): Kobas for in-venue and Deliveroo, Slerp for delivery, Mapal for specs. Extends the CJ1 ontology (Tab, Payment, Receipt, Discount are the same classes). Not a formal ontology.
