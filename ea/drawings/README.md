# Maki & Ramen EA drawings (customer journeys)

Method: Marcel Donges' 5-layer enterprise architecture (notes/marcel-ea-method.md).
Board: https://miro.com/app/board/uXjVESfEppc=/

## Rule: nothing is overwritten
- One folder per drawing, one file per version: cj1/CJ1_2_ea_layers/v0.4.svg, v0.6.svg ...
- A new version is a new file. Older files stay.
- Every Miro frame title carries the version it shows, e.g. "CJ1 2 EA 5-layer view v0.6".
- Questions (pink stickies) live in questions.md and are never deleted; answers are added beside them.
- Changes per version are logged in CHANGELOG.md.
- source/ holds the HTML that renders the drawings (proof pages).
